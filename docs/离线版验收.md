# Linux x86_64 完整离线版验收

2026 年 10 月 7 日，完整离线包已在 `192.168.31.116` 的隔离环境完成验收。目标机无需安装 Python、SBY、Yosys、求解器或 Icarus，也无需联网获取依赖。已有工程重跑不调用模型。

## 下载和使用

从 [GitHub Release](https://github.com/ysyx-22040210-yudian/UCAgent-DMAC-verification/releases/tag/v2026.10.07-offline) 下载 `UCAgent-DMAC-20261007-linux-x86_64.tar.gz` 和同名 `.sha256` 文件。仓库源码 ZIP 不包含完整运行时。

```sh
sha256sum -c UCAgent-DMAC-20261007-linux-x86_64.tar.gz.sha256
tar -xzf UCAgent-DMAC-20261007-linux-x86_64.tar.gz
cd UCAgent-DMAC-20261007-linux-x86_64
./Check-Package
./Start-UCAgent
# 纯 SSH 环境使用命令行：
./Run-DMAC --suite all
```

Linux 桌面启动需要可用的图形显示环境；命令行回归不需要。运行服务保留 10 GiB 可用磁盘的门槛，需为解压和新结果预留空间。启动目录可搬迁，也可以包含空格。

首次启动自动导入 `sby_counter`、`sby_counter_bug`、`DMAC-native`、`DMAC-main`。新设备不继承历史运行、审批或通过状态。项目副本与运行结果保存在用户数据目录；重启会保留已有修改。原始验证报告和证据另存于包内 `project/verification/reports/`。

## 实际验收结果

使用 CentOS 7 x86_64 虚拟机中的普通用户，在仅有 loopback 的独立网络命名空间运行。执行 PATH 仅含包内工具和系统基础命令；未借助宿主机安装的 SBY 或 Python。完整包搬入含空格目录后执行后端、命令行和桌面验收。

| 检查 | 结果 |
| --- | --- |
| 包内文件和链接校验 | 40,929 项全部匹配 |
| 新用户启动 | 四个项目自动导入，历史运行数为 0 |
| 重启与数据保留 | RTL 修改、项目和新运行历史保留 |
| 桌面 | 实际创建 Tk 窗口并显示项目列表，无回调错误 |
| Counter 正向证明 | 通过，1 条断言获证 |
| Counter 故障工程 | 检出预期反例，显示失败 |
| DMAC-native 后端证明 | 58 条断言获证；17 条 Cover 因 prove 模式未启用 |
| DMAC-main 后端 BMC | 63 条断言在深度 12 内无反例，显示未决 |
| 完整命令行回归 | 18 个 SBY 任务均符合预期结果 |
| 动态回放 | 19 次 Icarus 编译及回放均符合预期 |
| 启动/工具链/项目导入回归 | 19 个 Python 测试通过 |
| 压缩包搬运检查 | 另一个目录解压后，完整性检查及启动诊断通过；最终修改文件另逐项核对 |

18 个 SBY 任务包括四组原生安全证明、五组原生/FIFO 覆盖、七组故障对照、主任务 BMC 和主任务 Cover。七组故障对照产生预期 FAIL 与反例，属于验收成功。主任务 Cover 仍有未命中项，结果保持未决；不能据此宣称 DMAC 全部主任务属性获证。FormalMC、VCS 未在本次离线验收中运行。

首次验收发现 Icarus 内部编译辅助程序无法处理带空格的安装路径。现通过临时私有、无空格的编译目录别名调用原包内辅助程序；不更换二进制。修复后重新完成 18 个任务和 19 次回放，并核对最终归档文件。
